# Booking

Booking documentation is organized by document purpose:

- `brd/`: business requirements; use `BRD-BKG-0001-<slug>.md` naming.
- `optional-validations/`: optional validation rules, applicability, and user/partner impact.
- `specs/`: functional and technical behavior, including workflows and interfaces.
- `release-notes/`: user- and partner-facing changes.

Cross-link related booking documents and identify channel-specific behavior using the [channel matrix](../01-reference/channel-matrix.md).
