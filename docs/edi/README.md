# EDI documentation

- [`message-guides/`](message-guides/): message-level standards and usage guides.
- [`carrier-ig/`](carrier-ig/): partner-specific implementation guides, one folder per carrier.
- [`mappings/`](mappings/): field-level source-to-target mapping tables.

Use the [EDI implementation guide template](../../templates/edi-implementation-guide-template.md). Record standard/version, direction, partner scope, code-list provenance, acknowledgements, and error handling.
