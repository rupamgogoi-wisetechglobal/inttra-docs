# Code-list sources

This page records provenance and maintenance guidance; it is not a substitute for the authoritative, current code-list releases. Confirm the applicable version and partner profile before implementation.

| Code list | Authority / source | Usage notes |
|---|---|---|
| UN/LOCODE | [UNECE UN/LOCODE](https://unlocode.unece.org/publications) | Record the release/version used by the interface. Check location and function fields as required by the message profile. |
| SCAC | [NMFTA SCAC resources](https://www.nmfta.org/scac) | Confirm current licensing, validity, and carrier identity requirements with the responsible team. |

## Maintenance

For each interface, document accepted values, source release, validation behavior, and update owner in its mapping or implementation guide. Do not copy external lists into this repository without confirming redistribution terms and establishing an update process.
